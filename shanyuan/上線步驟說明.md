# 善緣地圖 — 上線步驟說明

完全不需要寫程式，照以下步驟做即可讓網站上線。

---

## 第一步：建立 Supabase 資料庫（約 10 分鐘）

### 1. 建立帳號
前往 https://supabase.com → 點「Start your project」→ 用 GitHub 帳號登入（沒有 GitHub 帳號請先到 github.com 免費註冊）

### 2. 建立新專案
- 點「New project」
- Project name：輸入 `shanyuan`
- Database Password：設一個你記得的密碼
- Region：選 `Southeast Asia (Singapore)`
- 點「Create new project」（等待約 1 分鐘）

### 3. 建立資料表
進入專案後，點左側選單「SQL Editor」，貼上以下 SQL 並點「Run」：

```sql
-- 文章資料表
create table posts (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users not null,
  title text not null,
  body text not null,
  cat text default '拜訪心得',
  org text default '',
  created_at timestamptz default now()
);

-- 收藏資料表
create table favourites (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users not null,
  org_name text not null,
  created_at timestamptz default now(),
  unique(user_id, org_name)
);

-- 讓登入的使用者可以讀寫自己的資料（安全設定）
alter table posts enable row level security;
alter table favourites enable row level security;

create policy "使用者可讀取所有文章" on posts for select using (true);
create policy "使用者可新增自己的文章" on posts for insert with check (auth.uid() = user_id);
create policy "使用者可刪除自己的文章" on posts for delete using (auth.uid() = user_id);

create policy "使用者可讀取自己的收藏" on favourites for select using (auth.uid() = user_id);
create policy "使用者可新增收藏" on favourites for insert with check (auth.uid() = user_id);
create policy "使用者可刪除收藏" on favourites for delete using (auth.uid() = user_id);
```

### 4. 取得 API 金鑰
- 點左側「Settings」→「API」
- 複製「Project URL」（格式：https://xxxx.supabase.co）
- 複製「anon public」金鑰（一長串文字）

---

## 第二步：填入設定值到網站檔案

用記事本（或任何文字編輯器）打開 `index.html`，找到以下兩行：

```
const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

改成（記得加單引號）：

```
const SUPABASE_URL = 'https://你的專案網址.supabase.co';
const SUPABASE_ANON_KEY = '你的anon金鑰';
```

存檔。

---

## 第三步：上傳到 GitHub（約 5 分鐘）

### 1. 建立 GitHub 帳號
前往 https://github.com → 「Sign up」免費註冊

### 2. 建立新 Repository
- 點右上角「+」→「New repository」
- Repository name：`shanyuan`
- 選「Public」
- 點「Create repository」

### 3. 上傳檔案
- 在新建的 repository 頁面，點「uploading an existing file」
- 把 `index.html` 拖進去
- 點「Commit changes」

---

## 第四步：用 Vercel 上線（約 3 分鐘）

### 1. 建立 Vercel 帳號
前往 https://vercel.com → 「Start Deploying」→ 用 GitHub 帳號登入

### 2. 匯入專案
- 點「Add New Project」→「Import Git Repository」
- 找到剛才建立的 `shanyuan` repository → 點「Import」
- 直接點「Deploy」（不需要改任何設定）

### 3. 完成！
Vercel 會給你一個網址，格式像 `shanyuan.vercel.app`，這就是你的網站！

---

## 之後買網域怎麼綁定？

1. 買好網域後（推薦 GoDaddy 或 Gandi）
2. 在 Vercel 專案設定裡點「Domains」
3. 輸入你的網域名稱，依指示設定 DNS
4. 約 10 分鐘後生效

## 常見問題

**Q：網站出現「無法載入文章」怎麼辦？**
A：檢查 `index.html` 裡的 SUPABASE_URL 和 SUPABASE_ANON_KEY 是否正確填入。

**Q：收藏後重新整理消失了？**
A：確認已登入。未登入時收藏不會儲存。

**Q：想新增更多公益團體怎麼做？**
A：告訴 Claude 你想新增哪些團體，他可以幫你更新 `index.html` 的 ORGS 資料。
